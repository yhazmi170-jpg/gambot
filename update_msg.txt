v1.7.4 — Events, Wipe, Command Fixes & Backup Guard

NEW
- `v events` — **Reworked random events**: pool expanded from 32 to 57 events with new mechanics (trait discounts, crate discounts + pity boost, battle pass XP boost, hunt cap boost, autohunt swarm, streak shield, seal/essence rain). Events now fire on an irregular schedule (8-12 / 15-40 / 45-65 min bands) instead of the old 25-30 min metronome.
- `Aovo wipe @user` — owner-only full account wipe (resets target to fresh: animals, balance, teams, perks, quests, bounties, stocks, vault, marriage, clan, pass, streaks, plots, bids, giveaways, achievements, lottery, cooldowns all cleared).

FIXES
- **Owner bypass**: you can now use disabled commands on any prefix (v/ovo), not just `A`. Previously only the admin prefix bypassed channel/server command disables.
- **Accurate disable message**: now says "disabled in this channel" vs "disabled in this server" depending on where the restriction was set.
- **Backup guard**: backup() refuses to push and restore() skips snapshots where a known active user appears wiped (balance≤1000 + 0 gambled + 0 won) — prevents a wiped/reset state from clobbering good cloud backups.
